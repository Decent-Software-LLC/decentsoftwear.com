# Decent Softwear — first wave

Local design preview for decentsoftwear.com. Three-product coming-soon page inspired by surfing, skating, music, Virginia and the Outer Banks.

Static site in `dist/`. No checkout, orders, prices, signup collection, or tracking. Product images and colors are illustrative launch concepts.

Preview: `python3 -m http.server 4173 --directory dist` and open http://localhost:4173.

Hosting: GitHub Pages, deployed from `dist/` by `.github/workflows/pages.yml` on pushes to `main`. Cloudflare manages DNS for `decentsoftwear.com`. Repository: https://github.com/Decent-Software-LLC/decentsoftwear.com.
